Álbum de Figurinhas

Um álbum de figurinhas interativo, em que a lógica em JavaScript controla a exibição e o preenchimento das figurinhas conforme elas vão sendo coladas.

JavaScript
Ver no GitHub Voltar ao portfólio

O que o projeto faz

O projeto simula um álbum de figurinhas: cada posição pode estar preenchida ou vazia, e o JavaScript é responsável por controlar esse estado — um exercício prático de lógica condicional e manipulação de elementos na página.
